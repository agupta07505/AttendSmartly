# 5W2H Framework — AttendSmartly

The **5W2H Framework** provides a comprehensive project analysis for **AttendSmartly - Attendance Tracker**.

---

## 1. WHAT (What is the project?)

**AttendSmartly** is a native Android application built using Kotlin and Jetpack Compose. It allows college students to track attendance across lectures, practical labs, and tutorials, configure custom unit counts, calculate safe bunks, receive automated class reminders, and maintain target attendance thresholds.

---

## 2. WHY (Why was it created?)

College students often face strict minimum attendance rules (e.g. 75% or 80%) with complex multi-hour class structures (labs count differently than single lectures). Existing apps treat every class as 1 unit or lack safe bunk calculation algorithms. AttendSmartly solves this by providing precise unit-based attendance tracking and instant bunk/recovery math.

## 4. WHERE (Where does it run & Where is data stored?)

- **Platform**: Android 7.0+ (API Level 24+).
- **Data Storage**: 100% offline-first local storage in an encrypted Room Database (`attendsmartly_database.db`) and Android DataStore Preferences on the user's device.

---

## 5. WHEN (When are operations triggered?)

- **Daily Class Schedule**: Updated in real-time as users log sessions or when scheduled classes occur.
- **Class Reminders**: Triggered before scheduled class times via background AlarmManager and WorkManager.
- **OCR Scan**: Triggered on-demand when users select a timetable photo to scan.

---

## 6. HOW (How is it built?)

- **Architecture**: Single-Activity, MVVM, Clean Architecture with Repository pattern.
- **UI Framework**: Jetpack Compose & Material Design 3.
- **Database**: Room Database with KSP & Kotlin Coroutines Flow.
- **Asynchronous Tasks**: WorkManager & AlarmManager.
- **Smart OCR**: Integration with Google Gemini Vision API for timetable image parsing.

---

## 7. HOW MUCH (How much does it cost?)

- **Cost**: 100% Free & Open Source.
- **Resource Footprint**: Minimal APK size, offline storage footprint under a few megabytes, zero telemetry bandwidth.
