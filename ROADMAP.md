# AttendSmartly — Feature Roadmap

This document outlines the planned feature roadmap for **AttendSmartly - Attendance Tracker**.

---

## 🎯 Short-Term Roadmap (v1.1 - v1.2)

### 📲 Home Screen Widgets
- [ ] **Quick Attendance Mark Widget**: Mark today's ongoing class as Present/Absent directly from Android Home Screen.
- [ ] **Percentage Glance Widget**: Display overall attendance percentage and safe bunk count on the home screen.

### 📅 Multi-Semester Archiving
- [ ] Archive past semester data while starting a fresh timetable for the new semester.
- [ ] Switch between past semesters in Analytics to view historical performance.

### 🔔 Smart Notification Enhancements
- [ ] Interactive notification action buttons for quick attendance logging.
- [ ] Custom reminder offset times (e.g., 5 mins, 15 mins, or 30 mins before class).

---

## 🚀 Medium-Term Roadmap (v1.3 - v2.0)

### 🔄 Calendar Integration
- [ ] Export class timetable to Google Calendar / Android System Calendar (`.ics`).
- [ ] Sync college holidays automatically with system calendar.

### 📊 Advanced Predictive Analytics
- [ ] "What-If" scenario simulator: Test custom future absence scenarios to project safe bunks.
- [ ] Semester completion projection: Estimated final attendance percentage based on remaining scheduled classes.

### 🎨 Custom UI Themes
- [ ] Additional Material 3 color presets & OLED true dark mode.
- [ ] Subject icon customizer and color palette picker.

---

## 🔮 Long-Term Vision (v2.0+)

- [ ] **Encrypted Cloud Backup Opt-In**: Optional Google Drive / WebDAV cloud backup for cross-device synchronization.
- [ ] **Wear OS Support**: View upcoming classes and log attendance from your smartwatch.
